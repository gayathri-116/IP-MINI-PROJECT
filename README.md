# Wanderly Tours (PHP + MySQL)
1. Install XAMPP (Apache + PHP 8 + MySQL).
2. Copy this folder to htdocs/wanderly.
3. Start Apache and MySQL, open phpMyAdmin, Import > database.sql.
4. Edit config.php if your MySQL user/password differ.
5. Visit http://localhost/wanderly/
Make an admin: register, then run
  UPDATE users SET role='admin' WHERE email='you@example.com';
Photos: put your own images in assets/img/<package-slug>/ (e.g. assets/img/goa-beach-break/1.jpg). They are shown first; missing slots use keyword photos from loremflickr.com (needs internet).
Illustrations: assets/img/<package-slug>/1-4.svg are generated by gen/gen.py (4 times of day per package). Replace any with your own photos (same folder, jpg/png/webp).
